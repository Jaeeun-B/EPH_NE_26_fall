`result-verifier` 에이전트를 써서 수치를 검증하세요.

대상: `$ARGUMENTS` (비었으면 `README.md`, `CLAUDE.md`의 "현재 결과" 절, `docs/*.md` 전부)

에이전트에게 다음을 분명히 전달하세요.

1. 문서의 모든 수치를 `outputs/`의 출처 파일과 대조할 것
2. `outputs/`가 비었거나 `datraj/`보다 오래됐으면 해당 스크립트를 먼저 돌릴 것
3. `06_run_b0.py`가 `[toppra]`로 돌았는지, 토크 사용률이 0.8 이하인지, 여유거리가 d_safe 이상인지 함께 볼 것
4. 반올림 차이는 불일치로 세지 말 것
5. **검증이 끝까지 돌지 못했으면 "이상 없음"으로 보고하지 말 것.** 확인하지 못한 범위를 밝힐 것

에이전트 보고를 받으면, 불일치가 있을 때만 어떻게 고칠지 제안하세요. 고치는 것은 사람의 확인을 받은 뒤에 합니다.
