방사선 파트에서 받은 선량 격자를 반영합니다. 받은 경로: `$ARGUMENTS`

## 1. 점검 (고치기 전에)

`handoff-checker` 에이전트로 먼저 점검하세요. 단위, 좌표계, 축 순서, 간격, 전/후 한 쌍, 이상값을 봅니다.

**점검에서 문제가 나오면 여기서 멈추고 보고하세요.** 틀린 격자로 돌린 결과는 틀린 결과입니다. 단위나 축 순서가 어긋나면 에러 없이 조용히 틀린 숫자가 나옵니다.

## 2. 반영

점검을 통과했으면:

1. 파일을 `data/dose_grids/`에 둡니다. 가상 격자는 지우지 말고 둡니다 (비교용)
2. `python scripts/06_run_b0.py --field grid --N 0`
3. `python scripts/07_run_b1.py --field grid --N 0`
4. `python scripts/10_export_handoff.py`

## 3. 달라진 것 정리

가상 선원 기준 결과와 비교해서 **결론이 바뀌었는지**를 봅니다. 숫자만 나열하지 마세요.

- 체류 75% / 직선 22% / 계획 3%라는 비중이 유지되는가. 이게 바뀌면 "자세 최적화 우선" 결론이 흔들립니다
- 최대 선량 부품이 여전히 C09인가
- 점 로봇(TCP) 값과 실제 최대 부품의 비가 어떻게 바뀌었는가. 이게 이 연구의 핵심 주장입니다
- 토크와 여유거리 제약은 그대로 지켜지는가

## 4. 문서 갱신

`doc-updater` 에이전트로 `README.md`, `CLAUDE.md`의 현재 결과 절, `docs/`의 분석 문서를 갱신합니다. **"가상 선원이라 절대값은 의미 없음"이라는 단서를 지우는 것을 잊지 마세요.** 이제 실제 격자입니다.

`docs/adr/`에 격자를 받은 날짜와 출처, 버전을 결정 기록으로 남기고, `docs/run_log.md`에 실행을 기록합니다.
