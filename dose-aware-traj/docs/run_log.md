# 실행 기록

스크립트를 돌릴 때마다 한 줄씩 **추가**합니다. 기존 줄은 고치지 않습니다. 그때 그 값이 나왔다는 것 자체가 자료입니다.

`/log-run` 명령으로 추가할 수 있습니다.

|---|---|---|---|---|---|---|---|---|---|
| 2026-10-01 | (커밋 전) | model | 189.9 | 0.776 | 0.031 | 75/22/3 | C09 | -0.3% | Linux 최초 기준선 |

## 읽는 법

- **B0 토크**: 경사 포락선 7조건 중 최대 사용률. 상한은 0.8
- **여유**: 계획 구간의 최소 여유거리. 기준은 `d_safe` = 0.02 m
- **체류/직선/계획**: 부품 선량 합의 구성 비율 (%)
- **B1 이동구간**: 이동 구간(S1, S3, S4, S6) 부품 선량 합의 B0 대비 변화

## 기록할 가치가 있는 것

코드를 고쳤을 때, 입력값이 바뀌었을 때, 설정(체류 시간, 속도, 질량)을 바꿨을 때. 같은 조건으로 그냥 다시 돌린 것은 기록하지 않습니다.
