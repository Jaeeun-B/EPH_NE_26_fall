# 불변식 (항상 성립해야 하는 조건)

코드가 바뀌어도 이 조건들은 성립해야 합니다. 깨지면 결과가 틀린 것이고, 에러 없이 조용히 깨지는 것도 많습니다. 검증할 때 이 목록을 기준으로 봅니다.

형식은 두 가지입니다.
- **불변식(I)**: 언제나 참이어야 하는 것
- **요구(R)**: 어떤 조건일 때 무엇이 되어야 하는 것 (WHEN → THEN)

## 단위와 좌표계

| 번호 | 조건 | 확인 방법 |
|---|---|---|
| I-01 | 코드 안의 모든 각도는 rad이다. deg는 표시할 때만 변환한다 | `datraj/` 전체. `deg`가 들어간 변수명은 입출력 경계에만 존재 |
| I-02 | 선량률의 단위는 Gy/h, 누적선량은 Gy이다. 문서에 mGy로 쓸 때만 1e3을 곱한다 | `dose_grid.py`의 메타 검사 |
| I-03 | 모든 위치는 `hotcell_world` 좌표계이다. 로봇 베이스 기준 좌표를 섞지 않는다 | `config/hotcell_layout.json`의 `frame` |
| I-04 | 격자의 축 순서는 xyz이다 | `_meta.json`의 `axis_order` |

## 물리

| 번호 | 조건 | 확인 방법 |
|---|---|---|
| I-05 | 선량률은 선원에서 멀어질수록 단조 감소한다 (차폐가 없을 때) | `03_validate_line.py` |
| I-06 | 누적선량은 음수가 될 수 없다 | `outputs/*/dose_by_component_*.csv` |
| I-07 | 베드 제거 후 격자의 값은 제거 전보다 크지 않다 | 두 격자 비교 |
| R-01 | 로봇이 정지해 있으면 → 그 구간 선량은 (선량률 × 시간)과 정확히 같다 | `04_validate_arc.py`의 오차 0.000% |
| R-02 | TCP가 선원에서 1 m 떨어진 원호를 돈다면 → TCP 선량은 Ḋ(1 m) × 시간과 같다 | `04_validate_arc.py` |

## 제약

| 번호 | 조건 | 확인 방법 |
|---|---|---|
| I-08 | 경사 포락선 7조건 전체에서 토크 사용률 ≤ 0.8 | `summary_*.json`의 `torque_ok`, `max_torque_utilization_envelope` |
| I-09 | 계획 구간의 최소 여유거리 ≥ `d_safe` + `e_track` | `summary_*.json`의 `min_clearance_plan_m`. 현재 `e_track = 0` |
| I-10 | 모든 관절 각도가 `position_lower` ~ `position_upper` 안에 있다 | `outputs/*/traj_*.csv` |
| I-11 | 속도와 가속도가 `velocity_limit`, `acceleration_limit` 이하이다 | TOPP-RA가 보장. 대체 방식일 때는 보장되지 않음 |
| R-03 | 운반물 질량이 늘어나면 → 허용 자세 범위는 좁아지기만 한다 | `08_payload_check.py` |

**I-09의 예외**: `05_solve_waypoints.py`의 "노즐 결합" 구간은 여유거리가 -0.000입니다. 결합 동작이라 접촉이 의도된 것이고, 이 구간은 계획 구간이 아니라 직선 구간이므로 I-09의 대상이 아닙니다.

## 방법론

| 번호 | 조건 | 확인 방법 |
|---|---|---|
| I-12 | 시간 배정은 TOPP-RA로 한다. 대체 방식(5차 다항식)으로 돌았으면 토크 제약이 반영되지 않은 것이다 | `summary_*.json`의 `timing_methods`에 `toppra`가 있는가. 로그에 `[quintic]`이 있으면 무효 |
| I-13 | B0와 B1은 같은 웨이포인트, 같은 선량장, 같은 제약으로 비교한다 | `06`, `07`의 `--field`, `--N` 인자가 같아야 함 |
| I-14 | 소재 파트 값이 없으면 `J_dose`와 `max_budget_usage`는 null이다. 임의의 값으로 채우지 않는다 | `summary_*.json` |

## 깨지면 조용한 것들

에러 없이 틀린 결과가 나오는 경우입니다. 특히 조심하세요.

- 격자 축 순서가 zyx인데 xyz로 읽기 (I-04)
- 단위가 mSv/h인데 Gy/h로 읽기 (I-02). 1000배 차이
- `e_track`이 mm인데 m로 읽기 (I-09). 1000배 차이
- toppra 미설치로 대체 방식 실행 (I-12). 토크 0.97이 0.78로 보고되지 않고 그냥 0.97이 나오는데, 이걸 못 보고 넘어가기 쉬움
- IK가 다른 해로 수렴해서 팔이 크게 도는데 TCP는 맞게 가는 경우. 2026-10-02에 B1에서 실제로 발생
