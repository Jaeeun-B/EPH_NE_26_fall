## 현재 상황

### 끝난 것

- macOS(M4 Pro) 환경 설정. 전체 스크립트가 끝까지 실행됨. Linux 결과와 부품 선량이 소수점 7자리까지 일치
- 검증 2종: 시간 적분·격자 보간 오차, 참고문헌 3 조건 재현
- B0 기준선 (RRT-Connect + 경로 단축 + TOPP-RA, 경사 포락선 토크 제약 포함)
- B1 (TCP 3D A* + IK 추종). 2026-10-02에 버그 수정
- 가반하중 점검 (허용 최대 17.1 kg)
- 다른 파트용 인계 파일 4종, 분석 문서

### 확인되지 않은 것

- 다른 파트 회신. 방사선 격자, 소재 `component_inputs.xlsx`, 제어 `e_track.csv` 모두 미수신
- 따라서 `J_dose`와 부품 예산 사용률은 아직 계산되지 않음 (`summary_*.json`에서 null)

### 다음 2주

1. P3 체류 자세 최적화 (S2, S3, S5에서 영공간으로 팔꿈치·손목 위치 변경)
2. 근접 구간 선량 적응 속도 α(s)
3. B0 다중 시드 (10회 이상) 평균·분산. 지금은 시드 하나라 B0와 B1 차이의 일부가 우연일 수 있음
4. P1 dose-aware RRT*, P2 STOMP
5. 방사선 격자가 오면 즉시 교체해서 재계산
