# ADR-0005: 타겟 = Xe 하나, MARINA 식 Xe 선원 상한으로 교체 조건 계산

- 날짜: 2026-10-11
- 상태: accepted (타겟/이중베드는 10/06 팀 회의 결정, 계산 방식은 E 파트 결정)
- 정한 사람: 팀 회의 (타겟), 백재은 (계산 방식)

## 배경

- 10/06 회의에서 흡착 타겟을 Xe 하나(주로 Xe-135)로, 이중베드 구조는 유지하기로 결정
  - 회의 전 정현 님 제안: Kr-85 하나, 이중베드 X
- 방사선 파트 격자는 아직 미수신
- 가상 선원으로는 "교체가 가능한가" 판단 불가

## 결정

1) 시뮬레이션 이중베드 구조(Bed A 교체, Bed B 운전) 그대로 사용, 선원은 Xe-133m, Xe-133, Xe-135만 둠
2) MARINA spec 유도값 시트 식 A = F·Y·ε·exp(-λt_d)·(1 - exp(-λT_on))을 베드 운전시간 T_on에 적용해서 선원 세기 상한 산출 (값/근거: `config/xe_bed.json`)
3) 이 상한으로 교체 주기, 부품 예산, 필요 차폐, 모듈 질량을 같이 계산 (`scripts/11_xe_bed_budget.py`)
4) 가상 선원 기준 기존 결과(06, 07)는 그대로 유지, 상대 비교용으로 계속 사용

## 검토한 대안

### 대안 A: 방사선 파트 격자가 올 때까지 대기
- 장점: 숫자를 두 번 만들 필요 없음
- 단점: 로봇 선택(17 kg 이상), 교체 개념 결정에 필요한 크기 판단이 늦어짐
- 버린 이유: 10/26 결론 확정까지 시간 부족. 크기 판단에는 상한으로 충분하다고 판단

### 대안 B: spec 7핵종(Kr 포함) 그대로 사용
- 버린 이유: 회의 결정과 맞지 않음. Kr-88, Kr-87 고에너지 감마가 들어가서 차폐 요구를 과대평가

## 결과

좋은 점
- 정현 님(파과), 서현 님(TID_lim), 유정 님(하중), 채원 님(선원) 값이 한 계산에서 연결됨
- "냉각해도 운전 중인 Bed B가 Xe-135로 다시 뜨거워짐" 같은 이중베드 고유 효과가 드러남

포기한 것
- 절대 선량 정확도 (ε = 1, 자체차폐/빌드업 없음 -> 상한)

위험
- 상한 숫자가 확정값처럼 인용될 수 있음 -> 문서마다 "상한 추정" 표기, 방사선 파트 값 오면 교체
