# ADR-0006: 선박 경사 조건에 IACS UR M46 정적 종경사 추가 검토

- 날짜: 2026-10-11
- 상태: proposed
- 정한 사람: 백재은 (E 파트), 유정 님과 협의 필요

## 배경

- ADR-0003은 46 CFR 58.01-40(정적 횡경사 15°, 동적 횡동요 22.5° + 종동요 7.5°)을 준용
- 팀 MARINA spec은 IACS UR M46 인용
  - UR M46 Rev.4(2024-08)에는 같은 값에 정적 종경사 5°가 추가로 있고, 횡경사/종경사가 동시에 생길 수 있다고 명시 (refs/notes/07)
  - 46 CFR에는 정적 종경사 X

## 결정 (제안)

- 경사 조건 7개 -> 13개
- 추가: 정적 종경사 ±5°, 정적 횡경사 ±15°와 종경사 ±5°의 동시 조합 4개

## 시험 결과 (2026-10-06, 임시 복사본)

| 항목 | 7조건 | 13조건 |
|---|---|---|
| iiwa 허용 최대 질량 | 17.1 kg | 17.1 kg |
| B0 토크 사용률 | 0.776 | 0.778 |
| B0 부품 선량 합 | 2.3612 Gy | 2.3631 Gy |
| B0 계획 구간 최소 여유 | 0.031 m | 0.028 m |

- 결론은 바뀌지 않음
- 저장소 설정을 바꾸지 않고 돌린 시험이라 `outputs/`에 결과 없음
- 채택 시 `config/shared_params.json` 수정 후 06, 07, 08, 12 재실행

## 검토한 대안

### 대안 A: 46 CFR 그대로
- 장점: 이미 돌린 결과와 동일
- 단점: spec이 인용한 기준과 다름

### 대안 B: IMO A.491(원자력 상선 코드) 30° / 45° / 10°
- 원자로 안전계통 기준이고, 정비 장비에 적용하라는 조항은 찾지 못함
- 정비는 잔잔한 바다나 정박 중에 한다는 운영 제한이 더 현실적일 것 같음

### 대안 C: 동적 가속도(롤 각가속도, heave)까지 반영
- 유정 님 ROS 2/Gazebo/Simulink 모델에서 다룰 부분
- E 파트는 준정적 경사 유지
