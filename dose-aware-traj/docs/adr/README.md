# 결정 기록 (ADR)

이 프로젝트에서 내린 결정과 **버린 대안**을 남깁니다. 나중에 "왜 그렇게 했냐"는 질문을 받을 때 꺼낼 수 있어야 합니다.

새로 쓸 때는 `/adr <주제>` 명령을 쓰거나 `template.md`를 복사합니다.

| 번호 | 제목 | 상태 | 날짜 |
|---|---|---|---|
| [0001](0001-component-level-dose.md) | 로봇을 점이 아니라 부품 단위로 평가한다 | accepted | 2026-09-27 |
| [0002](0002-reduced-bed-cartridge.md) | 베드를 축소 카트리지(9 kg)로 가정한다 | accepted | 2026-09-27 |
| [0003](0003-ship-inclination-envelope.md) | 선박 경사 조건을 46 CFR 58.01-40로 준용한다 | accepted | 2026-09-27 |
| [0004](0004-toppra-time-parameterization.md) | 시간 배정에 TOPP-RA를 쓰고 토크를 제약으로 넣는다 | accepted | 2026-09-30 |

## 상태의 뜻

- **proposed**: 제안됨. 아직 확정 아님
- **accepted**: 적용 중
- **deprecated**: 더 이상 쓰지 않음. 대체 결정 없음
- **superseded by ADR-NNNN**: 다른 결정으로 대체됨

## 언제 쓰는가

물리적 가정, 모델 선택, 알고리즘과 그 파라미터, 다른 파트와 합의한 규격. 되돌리기 어렵거나, 나중에 근거를 설명해야 하는 것.

변수명 변경이나 리팩터링처럼 되돌리기 쉬운 것은 쓰지 않습니다.

## 주의

0001~0004는 **결정이 내려진 뒤에 소급해서 작성**했습니다(2026-10-06). 당시 판단 근거를 코드와 설정에서 복원한 것이라, 그 시점의 논의를 전부 담지는 못합니다. 이후 결정은 내릴 때 바로 씁니다.
