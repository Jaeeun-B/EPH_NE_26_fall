# ADR-0008: P3 체류 자세 최적화는 웨이포인트 관절각 선택으로 구현

- 날짜: 2026-11-02
- 상태: accepted
- 정한 사람: 백재은 (E 파트)

## 배경

- 부품 선량 합의 75%가 체류, 22%가 베드 근처 직선 구간에서 발생 (B0)
- 경로 최적화(B1) 효과는 작업 전체 −0.6%
- 체류 중 TCP 위치와 공구 축은 고정이지만 공구 회전각과 7축 영공간이 남음

## 결정

1) 계획 구간 목표 자세 후보를 공구 회전 24개(15° 간격) × 영공간 기준 자세 21개로 생성
2) 후보마다 뒤따르는 근접 직선 구간을 실제로 풀고, 직선 + 체류 구간 부품 선량을 근사 계산
3) J = Σ D_k / TID_lim,k가 작은 순서로 후보를 넘기고, 나머지 작업이 풀리는 첫 후보 사용 (`datraj/posture.py`, `task.solve_chain(rank=...)`)
4) 경로계획(RRT-Connect + TOPP-RA)은 B0 그대로 -> B0와 차이는 자세 선택 하나

## 검토한 대안

### 대안 A: 체류 중 연속 최적화 (영공간 경사 하강)
- 단점: 체류 자세가 바뀌면 앞뒤 직선 구간도 같이 바뀌어야 해서 구간 연결이 복잡
- 버린 이유: 이산 후보 + 기존 체인 풀이 재사용이 더 단순하고 검증 쉬움

### 대안 B: TCP 선량 기준 자세 선택
- 버린 이유: TCP는 체류 중 고정이라 모든 후보가 같은 값 -> 선택 불가 (점 로봇 모델의 한계)

## 결과

좋은 점
- B0 대비 J −2.2%, 팔꿈치 주변 부품 최대 −9.4%. 작업시간·토크·여유거리 유지
- 점 로봇 모델에서는 보이지 않는 개선을 부품 모델로 보여줌

포기한 것
- 후보 IK 때문에 웨이포인트 풀이 시간 약 3 s -> 약 4.5분

위험
- 공구 회전 자유도는 원통형 손잡이 가정. 커플링 조작에 방향 제약이 있으면 효과가 줄어듦
- 6축 로봇(KR 계열)으로 바꾸면 영공간이 없어 공구 회전만 남음
