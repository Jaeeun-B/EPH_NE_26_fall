# 부품별 차폐·내방사선 입력 양식 (소재 파트용)

경로계획(E) 파트는 로봇 부품마다 누적선량을 따로 계산합니다.

D_k = S_k × ∫ Ḋ(p_k(t)) dt,  1회 작업 예산 B_k = TID_max,k / N_ex

여기 들어가는 투과율 S_k, 허용 누적선량 TID_max, 차폐재 질량을 `component_inputs.xlsx`에 채워 주세요.

## 작성 방법

1. `부품_입력` 시트의 노란 칸만 채웁니다. 5행은 형식 예시라 계산에서 빠집니다.
2. 투과율은 둘 중 하나로 넣습니다.
   - 차폐재, 두께 x(cm), μ/ρ(cm²/g), ρ(g/cm³)를 넣으면 S_k = exp(−(μ/ρ)·ρ·x) 가 자동 계산됩니다.
   - 따로 계산한 값이 있으면 `S_k 직접입력`에 넣습니다. 직접입력이 우선합니다.
   - 차폐가 없는 부품은 비워 두면 S_k = 1로 처리됩니다.
3. `TID_max`(Gy)와 근거(논문, 데이터시트, 시험 결과)를 함께 적어 주세요. 근거 없는 값은 결과 해석에 쓰기 어렵습니다.
4. `차폐재 질량`(kg)은 그 부품 위치에 점질량으로 더해 토크를 계산합니다. 차폐를 두껍게 할수록 선량은 줄고 토크 여유는 줄어드는 관계가 이 칸을 통해 결과에 드러납니다.
5. `설정` 시트
   - `N_ex`: 로봇 수명 동안 예상되는 베드 교체 횟수 (공정 파트와 협의)
   - `기준 감마 에너지`: μ/ρ를 고를 때 쓴 에너지. 방사선 파트와 같은 값이어야 합니다
   - `선량 매질`: 기본 Si
6. 파일 이름은 `component_inputs.xlsx` 그대로 회신해 주세요. E 파트 코드가 이 파일을 바로 읽습니다.

## 부품 목록

`부품_위치도` 시트와 `component_locations.png`에 위치가 있습니다.

| ID | 부품 | 위치 |
|---|---|---|
| C01~C07 | A1~A7 관절 구동부 (모터, 브레이크, 엔코더, 관절 토크센서) | 각 관절 축 중심 |
| C08 | 공구 구동부 (그리퍼·커플링 조작 액추에이터, 제어 보드) | 플랜지 앞 3 cm |
| C09 | 손목 카메라 | 공구 옆면 |
| C10 | 베이스 커넥터부 (전원·통신 케이블 인터페이스) | 베이스 뒤쪽 |

빠진 부품이 있거나 위치가 실제와 다르면 `비고`에 적어 주세요. 목록을 고쳐서 다시 보내 드리겠습니다.

## 참고

- 예시 행의 μ/ρ 0.1614 cm²/g는 NIST X-Ray Mass Attenuation Coefficients 표의 납 0.5 MeV 값입니다.
- 선량 단위를 Gy로 맞춘 이유: 로봇 부품의 TID와 바로 나누기 위해서입니다. Sv는 사람 기준 단위라 쓰지 않습니다.
