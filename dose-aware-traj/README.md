# Dose-aware trajectory optimization (E 파트)

MSR 오프가스 흡착 베드 교체 작업(S1~S6)에서 매니퓰레이터의 **부품별 누적선량**을 계산하고, 선량·시간·동역학 부하를 함께 보는 궤적 최적화기를 PyBullet으로 구현하는 저장소입니다. 지금은 계획서 진행 순서의 1~2단계(환경·인터페이스 구축, 해석해 검증, B0·B1 기준선, 부품 선량 평가기)까지 들어 있습니다.

환경 설정은 [SETUP.md](SETUP.md)를 따라 하면 됩니다.

```

  shared_params.json      로봇 관성·한계, 공구, 운반물, 경사 조건, 2관절 축약 모델 (제어 파트와 공유)
  components.json         선량 평가 부품 (C01~C10, 기준점 P0)
  virtual_sources.json    가상 선원 (방사선 파트 격자 오기 전까지)
  task.json               S1~S6 작업 정의 (대기 자세, 높이, 체류 시간, 계획기 설정)
datraj/                 코드
  dose_model.py           선량률 함수 인터페이스 (점·선 선원 해석식). 방사선 파트와 공유
  dose_grid.py            격자 읽기·검사·3선형 보간. 방사선 파트와 공유

  task.py                 S1~S6 웨이포인트, IK 체인, 궤적 조립

refs/                   참고문헌 PDF와 정리 노트 (PDF는 git 제외)
CLAUDE.md, .claude/     Claude Code 설정 (docs/claude-code-setup.md 참고)

outputs/                결과 (생성물, git 제외)
```

## 실행 순서

| 스크립트 | 계획서 항목 | 내용 |
|---|---|---|
| `00_check_env.py` | | 패키지 점검 |
| `01_make_virtual_grids.py` | 2. 선량장 인터페이스 | 가상 점·선 선원으로 베드 제거 전/후 격자 (N = 25, 50, 100) |
| `check_dose_grid.py` | 2. 선량장 인터페이스 | 격자 형식 점검과 단면 그림 (방사선 파트에도 전달) |
| `02_build_scene.py` | 2. 시뮬레이션 환경 | 배치도 → PyBullet 장면, 경사 중력 벡터, 장면 그림 (`--gui`) |
| `03_validate_line.py` | 5-1. 해석해 대조 | 점선원 옆 직선 통과: 시간 간격·격자 해상도별 오차 |
| `04_validate_arc.py` | 5-1. 참고문헌 3 재현 | 1 m 원호, 20 mm/s, 60 s: TCP와 부품별 선량 |
| `05_solve_waypoints.py` | 1-1. 단계 분해 | S1~S6 웨이포인트 IK (19개 구간) |
| `06_run_b0.py` | 4. 비교 알고리즘 B0 | RRT-Connect + 경로 단축 + TOPP-RA, 부품 선량·토크 평가 |
| `07_run_b1.py` | 4. 비교 알고리즘 B1 | TCP 3D A* (선량 가중) + IK 추종 |
| `08_payload_check.py` | 1-4. 동역학 제약 | 베드 질량별 경사 포락선 토크 점검 (회의 안건) |
| `10_export_handoff.py` | 7. 파트 간 입출력 | `handoff/` 인계 파일 생성 |

`06`, `07`은 `--field grid --N 100`으로 격자 경로를, 기본값 `--field model`로 해석식 경로를 씁니다. 방사선 파트 격자는 [data/dose_grids/README.md](data/dose_grids/README.md) 방식으로 넣고 `--field grid --N 0`으로 실행합니다. 소재 파트가 채운 `component_inputs.xlsx`는 `config/`에 넣으면 투과율 S_k, TID_max, 차폐재 질량이 자동으로 반영됩니다.

## 지금까지의 결과 (가상 선원, 배치 초안 기준)

선량 절대값은 가상 선원이라 의미가 없고, 상대 비교와 파이프라인 확인용입니다. 자세한 분석은 [docs/2026-10-02_baseline_analysis.md](docs/2026-10-02_baseline_analysis.md)에 있습니다.

**검증**
- 시간 적분: 경로 간격이 선원 수직거리의 0.4배 이하이면 오차 1% 미만. 100 Hz 샘플링(경로 간격 최대 1.1 cm)이면 충분.
- 격자 보간 (최대 오차): 2.0 cm 간격은 선원 10 cm 옆에서 0.6%, 4.1 cm 간격은 3.2%, 8.3 cm 간격은 32%. 방사선 파트에 2 cm 간격을 요청.
- 참고문헌 3 조건: TCP 선량이 Ḋ(1 m) × 60 s와 일치 (오차 0.000%). 같은 궤적에서 A4 구동부는 TCP의 4.9배를 받아 점 로봇 가정의 한계가 바로 드러남.
- B0 궤적을 격자와 해석식으로 각각 평가했을 때 부품 선량 차이: N=100이면 1% 이내, N=50이면 최대 3.5% (TCP).

**B0 기준선 (S1~S6 전체 교체 작업)**
- 총 190 s (동작 60 s, 체류 130 s). 경사 포락선 최대 토크 사용률 0.78 (상한 0.8), 계획 구간 최소 여유거리 3.1 cm.
- 부품 선량 합의 75%가 체류(S2 해제, S5 체결), 22%가 베드 근처 직선 구간(5 cm/s), 경로를 고를 수 있는 계획 구간은 3%뿐.
- 최대 선량 부품은 손목 카메라(C09). 점 로봇(TCP) 값은 실제 최대 부품보다 1.7배 크게 나옴 (TCP가 손잡이에 가장 가까움).
- B1(TCP A*)은 계획 구간 선량을 21% 줄이지만 이동 구간 전체로는 -2.1%, 작업 전체로는 -0.6%. 계획 구간 비중이 작기 때문.

**가반하중**
- 운반 자세에서 허용되는 최대 베드 질량은 약 17 kg (A6 손목 토크가 경사 22.5°에서 한계). 축소 카트리지 9 kg은 여유 있음, ORNL 참고 베드(약 60 kg)는 불가.
- 운반 중 공구를 기울이면 A6가 먼저 한계에 닿아서, 운반 구간 탐색에서 정적 토크 초과 자세를 아예 제외함.

**시사점**: 지금 가정(체류 60 s, 근접 구간 5 cm/s)에서는 경로 선택(P1, P2)보다 체류·근접 구간의 작업 자세(P3)와 근접 구간 속도가 선량을 좌우합니다. 체류 시간과 근접 속도는 공정·제어 파트 값으로 바꾼 뒤 다시 확인해야 합니다.

- 여유거리 2 cm (e_track = 0, 제어 파트 값 오면 반영)
