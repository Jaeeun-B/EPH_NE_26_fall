## 프로젝트와의 관계

- 프로젝트의 B0(RRT-Connect + 경로 단축 + TOPP-RA)와 B1(TCP A* + IK 추종 + TOPP-RA)의 인용 근거 갈래입니다. `docs/adr/0004-toppra-time-parameterization.md`가 TOPP-RA 선택을 설명합니다.
- RRT-Connect 다음에 TOPP-RA를 붙인 파이프라인은 고정된 기하 경로 위의 시간만 최적화하므로 경로와 시간의 결합 최적이 아닙니다. 원자료 노트의 추론입니다(TOPP-RA가 경로 매개화 방법이라는 사실에서 따라옴).
- 다목적 도구(NSGA-II, 엡실론 제약)는 선량, 시간, 토크의 동시 고려에 쓰일 후보입니다. 엡실론 제약의 1차 문헌은 Haimes 1971로 제목, 권호, 쪽, DOI까지 확인했고 저자 표기만 남았습니다(4.14).
- 새 방향(2026-10-11)에서 이 갈래는 재은(경로, 선량, 시간, 로봇 시뮬레이션)이 씁니다. 로봇이 KR 계열로 바뀌면 TOPP-RA의 토크 제약에 들어갈 동역학 모델이 바뀌고(`12_대형로봇_후보.md`), 6축이면 P3가 쓸 여유 자유도가 사라집니다(아래 "프로젝트 자체 유도"의 P3 절). 아래 "프로젝트 자체 유도" 절은 P3와 α(s)의 기대치를 좁히는 결과라 계획 단계에서 먼저 확인할 것입니다.

## 문헌별 정리

### 4.1 Pham, Pham (TOPP-RA) 　검증: verified (2026-10-11 Crossref 등록 기록으로 IEEE DOI 확인)

- 서지: "A New Approach to Time-Optimal Path Parameterization Based on Reachability Analysis", arXiv:1707.07239 [cs.RO], 2017-07-23 제출, 2017-11-22 개정, 15쪽 9그림, arXiv DOI 10.48550/arXiv.1707.07239. 저널판은 IEEE Transactions on Robotics 34(3), 645-659 (2018)이며 공식 저장소 README가 적은 값입니다. https://arxiv.org/abs/1707.07239 , https://github.com/hungpham2511/toppra . 저자 소속은 난양공대(NTU)입니다. (2026-10-06) IEEE DOI는 어떤 페이지에서도 확인되지 않았습니다. **(2026-10-11) Crossref 등록 기록으로 Hung Pham, Quang-Cuong Pham, IEEE Transactions on Robotics 34(3), 645-659, 2018(published-print 2018-06), DOI 10.1109/TRO.2018.2819195를 확인했습니다.** https://api.crossref.org/works/10.1109/TRO.2018.2819195 . 추정했던 DOI가 맞았으므로 이제 인용할 수 있습니다.
- 파일: `pham2018_toppra` (PDF 없음)
- 한 줄 요약: 도달가능성 해석으로 경로 매개화를 풀어 속도, 가속도, 토크 같은 제약 아래 시간 최적 매개화를 구하는 방법입니다.
- 프로젝트와의 관계: B0, B1의 시간 배정(`datraj/timing.py`)이 이 방법입니다.
- 방법: 일반화된 2차 제약을 쓰고, 토크 한계는 그 예로 다룹니다. 콜로케이션 이산화로 격자점마다 선형 부등식이 됩니다.

$$A(q)\ddot q + \dot q^\top B(q)\dot q + f(q) \in C(q)$$

$$M(q)\ddot q + \dot q^\top C(q)\dot q + g(q) = \tau,\quad \tau_i^{\min} \le \tau_i(t) \le \tau_i^{\max}$$

경로 매개변수 관계를 대입하면 격자점 i마다 $a_i u_i + b_i x_i + c_i \in C_i$ 꼴입니다(u는 경로 가속도, x는 경로 속도의 제곱).

쓸 수 있는 수치와 보증

| 값 | 조건 | 위치 |
|---|---|---|
| 충분히 촘촘한 격자(Δ < Δ_thr)에서 반환된 매개화는 최적 | | 정리 2 (절 번호 미표시) |
| 영관성(zero-inertia) 점에서 비용 격차 J* - J† = O(Δ) | 점근적으로 격차가 0으로 수렴 | 정리 3 (절 번호 미표시) |
| 일반화 2차 제약과 토크 한계 정의 | | II-A절, Eqs. 2-3 |
| 콜로케이션으로 격자점마다 선형 부등식 | | III-B절 |
| 콜로케이션 오차 O(Δ), 1차 보간 오차 O(Δ^2) | 제약을 격자점에서만 강제하기 때문 | 부록 D, III-B절 |
| 시험 사례에서 100% 성공률 주장 | 다른 최신 방법들에서는 실패가 보고됨 | arXiv 초록 |

- 실패 모드: 제어 가능 집합이 비거나 시작 상태가 $K_0$ 밖이면 Infeasible을 보고합니다(해당 문장의 절 번호 미상). 영관성 점은 TOPP 일반에서 어려운 지점이고 TOPP-RA의 LP 접근은 이를 더 강건하게 다룬다고 서술합니다. 경사로 중력항이 빠르게 변하는 경로에서 격자가 성기면 이산화 오차가 커질 수 있습니다(추론).
- 우리와 다른 점: 경로가 고정되고 시간만 최적화됩니다. toppra 파이썬 API에서 토크 제약 클래스가 노출되는지는 문서에서 확인하지 못했습니다. 저장소 README는 파이썬 지원 중단을 예고하고 있어 유지보수 위험이 있습니다. 토크 제약에는 동역학 모델(M, C, g)이 필요하고 프로젝트의 iiwa 식별 문헌은 찾지 못했습니다.
- 2026-10-11 추가(프로젝트 자체 유도, 아래 "프로젝트 자체 유도" 절): 제약이 경로 위 각 점에서 (b, b')에만 의존하면 TOPP-RA의 시간최적 해가 곧 선량최적 해입니다. 그래서 B0, B1의 TOPP-RA 구간에서 α(s)가 선량을 더 줄일 여지는 경쟁 목적이나 3차 제약이 있을 때만 생깁니다.
- 확인 못 한 것: 정리 2와 3의 절 번호, API 참조 문서의 토크 제약 클래스 이름, GitHub 이슈 수준의 실제 실패 보고. (IEEE DOI는 2026-10-11 해결)

### 4.4 Debrouwere et al. (2013) 　검증: verified (2026-10-11 본문 일부 확인)

- 서지: "Time-optimal path following for robots with convex-concave constraints using sequential convex programming", IEEE Transactions on Robotics 29(6), 1485-1495, DOI 10.1109/TRO.2013.2277565. https://infoscience.epfl.ch/handle/20.500.14299/99981

- 2026-10-11 보강: 저자 전체는 Debrouwere, Van Loock, Pipeleers, Tran Dinh, Diehl, De Schutter, Swevers입니다. KU Leuven Lirias PDF(https://lirias.kuleuven.be/retrieve/264560)에서 본문 일부를 읽었습니다. 식 (5) b(s) = ṡ²와 시간 목적 T = ∫ 1/√b(s) ds(s는 0에서 1, II절), "the objective function can for instance be supplemented with thermal energy terms or integrals of the absolute value of the rate of change of the torque"(II절), 그리고 초록의 "velocity-dependent torque constraints or torque rate constraints ... destroy the convexity"입니다.
- 프로젝트와의 관계(보강): 선량 항을 기존 볼록 시간최적 틀에 "목적 추가"로 넣을 수 있다는 형식적 근거입니다. 속도 의존 토크 제약을 쓰면 볼록성이 깨진다는 점을 함께 적어야 합니다.
- 우리와 다른 점: 해당 없음.

### P3 (체류 자세의 영공간 최적화)

- 정식화: 체류 중 부품 선량은 D_k = S_k T_dwell Ḋ(p_k(q))이므로 P3는 자기운동 다양체 {q : f(q) = x_task} 위에서 H(q) = Σ_k (S_k/B_k) Ḋ(p_k(q))를 최소화하는 정적 문제입니다. 그래디언트는 ∇_q H = Σ_k (S_k/B_k) J_{p_k}(q)ᵀ ∇_p Ḋ(p_k)이고 점선원 역제곱(Ḋ = A/r²)이면 ∇_p Ḋ = -2A(p - p_s)/r⁴입니다. Liégeois식 갱신은 q̇ = J⁺ẋ - k(I - J⁺J)∇_q H입니다(4.15).
- 단일 부품이면 거리 최대화(4.16)와 선량률 최소화가 같은 해를 주지만 여러 부품을 S_k/B_k로 가중하면 해가 달라집니다.
- **범위의 상한(가장 중요)**: 7축 팔에 6차원 말단 자세를 완전히 구속하면 자기운동은 1차원(팔꿈치 회전, arm angle)입니다. iiwa 같은 S-R-S 구조라면 어깨 중심과 손목 중심은 고정되고 팔꿈치 부근만 원호를 따라 움직입니다. 위치 기반 점선원 모델에서 P3가 바꿀 수 있는 것은 팔꿈치 주변 부품(관절 3, 4 구동부와 인접 링크)의 선량뿐이고, 선원에 가장 가깝고 선량률이 가장 높은 손목, 말단, 말단 카메라는 줄일 수 없습니다(Zhang 2020 Table 1에서도 관절 7 쪽이 가장 높음, 01 1.1). 따라서 체류 선량 중 P3가 줄일 수 있는 몫은 팔꿈치 부근 부품의 비중에 묶입니다. 넓히려면 공구 축 회전 같은 기능적 여유도를 풀거나(4.20) 체류 위치를 허용 영역 안에서 함께 골라야 합니다.
- 6축 로봇(KR QUANTEC 등)으로 바꾸면 6차원 말단 자세를 완전히 구속할 때 자기운동이 없으므로(일반 자세에서 여유 자유도 0) P3는 과업 구속을 풀지 않는 한 쓸 수 없습니다. 이 문장은 위 유도를 6축에 적용한 이 노트의 추론이며 원자료 노트에는 없습니다. 로봇 선택(`12_대형로봇_후보.md`)과 함께 팀이 확인해야 합니다.
- 자기운동이 1차원이면 그래디언트보다 arm angle 전 구간 격자 탐색이 국소 최소를 피하면서 관절 한계와 충돌을 함께 검사할 수 있어 낫습니다.
- 점선원 역제곱 모델에는 링크의 자기 차폐가 없으므로 P3의 이득은 거리 증가에서만 나옵니다.

### α(s) (고정 경로 위 속도 조절)

- 정식화: 고정 경로 q(s), s ∈ [0, 1]에서 dt = ds/ṡ이고 b = ṡ²이므로 D_k^transit = S_k ∫ Ḋ(p_k(q(s)))/√b(s) ds입니다. w_k(s) = S_k Ḋ(p_k(q(s))) ≥ 0은 경로가 정해지면 격자 위에서 미리 계산됩니다. b > 0에서 1/√b는 볼록이므로 Σ_k D_k/B_k는 b에 대해 볼록이고, Verscheure, Debrouwere(4.4), Lipp과 Boyd(4.18) 틀에 목적으로 넣든 ε 제약 D_k ≤ ε_k로 넣든 볼록성이 유지됩니다. 속도 의존 토크 제약은 원래 틀의 볼록성 자체를 깹니다(4.4 초록).
- **시간최적이 곧 선량최적**: 제약이 각 s에서 (b, b')에만 의존하는 형태(속도, 가속도, a u + b x + c ∈ C 꼴 토크 제약)라면 두 가능 프로파일의 점별 최댓값도 가능하므로 점별로 가장 큰 가능 프로파일 b*가 존재합니다. b*는 시간최적이면서 동시에 임의의 w ≥ 0에 대해 ∫ w/√b를 최소화합니다. 즉 같은 제약에서는 TOPP-RA(4.1)의 시간최적 해가 선량최적 해입니다. 이 등가는 (i) 저크나 토크 변화율 같은 3차 제약이 있을 때, (ii) 에너지, 저크, 추적 정확도, 카메라 모션 블러 같은 경쟁 항이 목적에 있을 때, (iii) 이산화에서 두 프로파일이 교차할 때 깨집니다. 같은 격자에서 TOPP-RA 결과와 선량 가중 볼록 해를 비교하면 바로 확인할 수 있습니다.
- 보고 방식: α(s)의 효과는 (1) 현재 속도 프로파일에서 시간최적 프로파일로 옮겨 생기는 감소와 (2) 경쟁 목적이 있을 때 선량률 낮은 구간에서 감속하고 높은 구간에서 가속하는 재분배 감소로 나눠 보고해야 하며, (2)만 선량 고유 효과입니다.
- 상한: α(s)는 체류 선량을 건드리지 못하므로 접근과 이동 몫 안으로 제한됩니다. 접근 구간은 체류 자세에서 정지해야 하므로(b(1) = 0) 선원에 가까운 끝부분일수록 속도가 0에 가까워 실제 감소폭은 접근 몫보다 훨씬 작을 가능성이 높습니다.

### 다목적 정식화

- 두 결과를 합치면 고정 경로의 속도 조절만으로는 "시간 대 선량" Pareto 전선이 거의 한 점으로 줄어듭니다. 의미 있는 상충은 α(s)에서의 선량 대 저크(또는 에너지)와, 경로와 P3 자세 선택에서의 선량 대 시간입니다. Pareto 그림은 이 두 축으로 그립니다.
- 방법 선택: 볼록한 α(s)에는 ε-constraint("min 저크 s.t. D_k ≤ ε_k", ε_k를 예산 비율로, 4.14 Haimes), 비볼록한 경로와 자세 결합 문제에는 NSGA-II(4.11)나 Ye 2024(4.19) 같은 비지배 정렬 메타휴리스틱이 맞다는 것이 원자료 노트의 판단입니다.
- 팀에 대한 결정 요청(보고서 6절): 현재 속도 프로파일이 시간최적인지 확인하고 α(s)에 경쟁 목적(저크, 에너지)을 둘지 정하기, 로봇 기구 구조(S-R-S 여부)와 공구 축 회전이 과업상 자유인지와 체류 위치의 허용 영역 확인(`00_확인필요_목록.md`).
