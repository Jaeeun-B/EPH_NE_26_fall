## 프로젝트와의 관계

- 프로젝트의 B0(RRT-Connect + 경로 단축 + TOPP-RA)와 B1(TCP A* + IK 추종 + TOPP-RA)의 인용 근거 갈래입니다. `docs/adr/0004-toppra-time-parameterization.md`가 TOPP-RA 선택을 설명합니다.
- RRT-Connect 다음에 TOPP-RA를 붙인 파이프라인은 고정된 기하 경로 위의 시간만 최적화하므로 경로와 시간의 결합 최적이 아닙니다. 원자료 노트의 추론입니다(TOPP-RA가 경로 매개화 방법이라는 사실에서 따라옴).
- 다목적 도구(NSGA-II, 엡실론 제약)는 선량, 시간, 토크의 동시 고려에 쓰일 후보입니다. 엡실론 제약의 1차 문헌은 확보하지 못했습니다.

## 문헌별 정리

### 4.1 Pham, Pham (TOPP-RA) 　검증: partial (IEEE DOI 미확인)

- 서지: "A New Approach to Time-Optimal Path Parameterization Based on Reachability Analysis", arXiv:1707.07239 [cs.RO], 2017-07-23 제출, 2017-11-22 개정, 15쪽 9그림, arXiv DOI 10.48550/arXiv.1707.07239. 저널판은 IEEE Transactions on Robotics 34(3), 645-659 (2018)이며 공식 저장소 README가 적은 값입니다. https://arxiv.org/abs/1707.07239 , https://github.com/hungpham2511/toppra . 저자 소속은 난양공대(NTU)입니다. **IEEE DOI는 어떤 페이지에서도 확인되지 않았습니다.** 기억에서 검색했던 10.1109/TRO.2018.2819195는 확인되지 않았으므로 사용하지 않습니다.
- 파일: `pham2018_toppra` (PDF 없음)
- 한 줄 요약: 도달가능성 해석으로 경로 매개화를 풀어 속도, 가속도, 토크 같은 제약 아래 시간 최적 매개화를 구하는 방법입니다.
- 프로젝트와의 관계: B0, B1의 시간 배정(`datraj/timing.py`)이 이 방법입니다.
- 방법: 일반화된 2차 제약을 쓰고, 토크 한계는 그 예로 다룹니다. 콜로케이션 이산화로 격자점마다 선형 부등식이 됩니다.

$$A(q)\ddot q + \dot q^\top B(q)\dot q + f(q) \in C(q)$$

$$M(q)\ddot q + \dot q^\top C(q)\dot q + g(q) = \tau,\quad \tau_i^{\min} \le \tau_i(t) \le \tau_i^{\max}$$

경로 매개변수 관계를 대입하면 격자점 i마다 $a_i u_i + b_i x_i + c_i \in C_i$ 꼴입니다(u는 경로 가속도, x는 경로 속도의 제곱).

쓸 수 있는 수치와 보증

| 값 | 조건 | 위치 |
|---|---|---|
| 충분히 촘촘한 격자(Δ < Δ_thr)에서 반환된 매개화는 최적 | | 정리 2 (절 번호 미표시) |
| 영관성(zero-inertia) 점에서 비용 격차 J* - J† = O(Δ) | 점근적으로 격차가 0으로 수렴 | 정리 3 (절 번호 미표시) |
| 일반화 2차 제약과 토크 한계 정의 | | II-A절, Eqs. 2-3 |
| 콜로케이션으로 격자점마다 선형 부등식 | | III-B절 |
| 콜로케이션 오차 O(Δ), 1차 보간 오차 O(Δ^2) | 제약을 격자점에서만 강제하기 때문 | 부록 D, III-B절 |
| 시험 사례에서 100% 성공률 주장 | 다른 최신 방법들에서는 실패가 보고됨 | arXiv 초록 |

- 실패 모드: 제어 가능 집합이 비거나 시작 상태가 $K_0$ 밖이면 Infeasible을 보고합니다(해당 문장의 절 번호 미상). 영관성 점은 TOPP 일반에서 어려운 지점이고 TOPP-RA의 LP 접근은 이를 더 강건하게 다룬다고 서술합니다. 경사로 중력항이 빠르게 변하는 경로에서 격자가 성기면 이산화 오차가 커질 수 있습니다(추론).
- 우리와 다른 점: 경로가 고정되고 시간만 최적화됩니다. toppra 파이썬 API에서 토크 제약 클래스가 노출되는지는 문서에서 확인하지 못했습니다. 저장소 README는 파이썬 지원 중단을 예고하고 있어 유지보수 위험이 있습니다. 토크 제약에는 동역학 모델(M, C, g)이 필요하고 프로젝트의 iiwa 식별 문헌은 찾지 못했습니다.
- 확인 못 한 것: IEEE DOI, 정리 2와 3의 절 번호, API 참조 문서의 토크 제약 클래스 이름, GitHub 이슈 수준의 실제 실패 보고.

### 4.3 Shin, McKay (1985) 　검증: partial (쪽수 상충, DOI 미확인)

- 서지: "Minimum-Time Control of Robotic Manipulators with Geometric Path Constraints", IEEE Transactions on Automatic Control AC-30(6), 1985-06. 저자 호스팅 PDF 머리말은 531-540, 흔히 인용되는 값은 531-541로 상충합니다. - 우리와 다른 점: 프로젝트 상한 0.8은 이 동기와 같은 방향입니다(`CLAUDE.md`의 토크 사용률 상한).
- 확인 못 한 것: 쪽수(531-540 대 531-541), DOI.
